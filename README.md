# Smart Emergency Assistance

A UI/UX design prototype for a smart healthcare and emergency assistance mobile application developed using Figma.

## Project Overview

Smart Emergency Assistance is a mobile application designed to help users monitor their health status, assess potential health risks, and quickly access emergency services when needed. The application focuses on providing a simple, user-friendly, and reliable healthcare experience.

## Key Features

- User Registration & Login
- Health Status Monitoring
- Risk Assessment Questionnaire
- Emergency SOS System
- Medical Data Confirmation
- Appointment Booking
- User-Friendly Interface
